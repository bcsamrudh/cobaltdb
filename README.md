# CobaltDB

CobaltDB is a lightweight in-memory key-value store written in Go, built as a
foundation for a distributed database.

## Project structure

```text
cobaltdb/
├── cmd/
│   ├── server/
│   └── cli/
├── internal/
│   ├── server/
│   ├── protocol/
│   └── store/
├── tests/
├── go.mod
├── README.md
├── LICENSE
└── .gitignore
```
